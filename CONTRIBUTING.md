# Contributing

Thank you for contributing to the QA Automation Portfolio project.

## Guidelines

* Create a separate branch for your changes.
* Follow the existing project structure and coding standards.
* Write clear and maintainable automation code.
* Add or update test cases when required.
* Run the relevant tests before committing your changes.
* Do not commit passwords, API keys, tokens, or other sensitive information.
* Use clear and meaningful commit messages.
* Create a Merge Request for review before merging changes into the main branch.

## Branch Naming

Use the following format:

* `feature/<name>`
* `bugfix/<name>`
* `test/<name>`
* `chore/<name>`

## Commit Messages

Use clear commit messages, for example:

* `Add login automation test`
* `Add API validation tests`
* `Update project documentation`
* `Fix test locator`

## Code Quality

Please ensure that:

* Code is readable and properly organized.
* Locators and test data are maintained appropriately.
* Tests are reliable and independent.
* Sensitive information is stored using environment variables or secure CI/CD variables.

Thank you!
